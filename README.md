#  Учет сетевой инфраструктуры и расхода материалов кабинета 319Б

> Веб-приложение для автоматизации учета сетевых точек, дефектов и фактического расхода материалов в кабинете **319Б**.

Проект разработан курсантами группы **21 ИСП**, подгруппа №1, в рамках учебной практики.

---

##  Кратко о проекте

Система предназначена для учета:

- сетевых точек кабинета;
- оборудования и его статусов;
- выявленных дефектов;
- фактического расхода материалов;
- действий пользователей в системе;
- отчетов по датам с возможностью печати и экспорта.

**Главный архитектурный принцип:**  
система фиксирует только факты использования материалов — **что, сколько и где было использовано**.

>  Складская логика, лимиты, остатки и проверки доступности материалов в проекте не реализуются.

##  Установка и запуск

### 1. Импорт базы данных

Импортируйте дамп базы данных:

```text
install/dump.sql
```

в MySQL через phpMyAdmin, MySQL Workbench или консоль.

---

### 2. Настройка подключения к БД

Откройте файл:

```text
config/db.php
```

и укажите параметры подключения:

```php
$host = 'localhost';
$dbname = 'ваша_база_данных';
$user = 'имя_пользователя';
$pass = 'пароль';
```

---

### 3. Размещение проекта

Поместите папку проекта в корень веб-сервера, например:

```text
htdocs/lvs
```

или:

```text
www/lvs
```

---

### 4. Учетные записи по умолчанию

| Роль | Логин | Пароль |
|---|---|---|
| Администратор | `admin` | `admin123` |
| Оператор | `operator` | `operator123` |

---

### 5. Запуск приложения

Откройте в браузере:

```text
http://localhost/lvs/public/auth/login.php
```

##  Основной функционал

###  Дашборд

На главной странице отображаются карточки статистики:

- общее количество сетевых точек;
- количество открытых дефектов;
- общий расход кабеля;
- краткие показатели по инфраструктуре.

---

###  Реестр оборудования

Модуль позволяет:

- просматривать список сетевых точек;
- фильтровать записи по типу;
- фильтровать записи по статусу;
- использовать пагинацию;
- добавлять новые точки;
- редактировать существующие точки;
- удалять точки при отсутствии связанных дефектов;
- автоматически учитывать связи с журналом дефектов.

---

###  Журнал дефектов

Функции модуля:

- регистрация дефектов;
- редактирование дефектов;
- фильтрация по критичности;
- фильтрация по статусу;
- смена статуса дефекта;
- автоматическое обновление статуса связанной сетевой точки.

---

###  Расход материалов

Система фиксирует фактический расход материалов:

- материал;
- количество;
- дату использования;
- связанную сетевую точку;
- связанный дефект;
- комментарий пользователя.

Также реализованы сводные карточки с агрегацией через `SUM`.

> Система не проверяет остатки и не ведет складской учет.

---

###  Отчеты

В разделе отчетов доступны:

- фильтрация по датам;
- просмотр расхода материалов;
- печатная версия отчета;
- экспорт данных в CSV.

---

###  Лог действий

Журнал действий доступен только пользователю с ролью **администратор**.

Фиксируются основные операции:

- вход в систему;
- добавление записей;
- изменение данных;
- удаление данных;
- смена статусов.

##  Требования безопасности

###  Реализовано

- Все SQL-запросы выполняются через `PDO::prepare`.
- Значения передаются через `bindValue`.
- Пароли хешируются через `password_hash`.
- Вывод данных экранируется через `htmlspecialchars`.
- После авторизации выполняется регенерация сессии.
- Конфигурационные файлы защищены от прямого вызова.

###  Запрещено

- Объектно-ориентированное программирование.
- Использование фреймворков.
- Массовое использование inline-стилей.
- Сложный JavaScript.
- AJAX для основных операций приложения.
